# 👋 Salut, moi c'est TMK-DEV !
Développeur full-stack Java / JavaScript  | Titre RNCP niveau 7 (Bac +5) « Expert en développement logiciel »

Je conçois et développe des applications web et mobiles de bout en bout, avec une attention particulière portée à la performance, à la scalabilité et à l'expérience utilisateur.

Au travers de mes expériences, jai été amené à intervenir sur l'ensemble du cycle de développement : de la conception fonctionnelle et technique (Merise, UML...) jusqu'au déploiement, en passant par le développement front-end et back-end, dans des environnements agiles (Scrum).

Ma stack technique couvre deux écosystèmes : 
- Front-end : React, React Native et Angular 
- Back-end : Node.js (Express, NestJS) ou Java (Spring Boot),
